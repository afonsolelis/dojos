Strings, Recursão e Backtracking

Hoje vamos desmontar strings, pensar recursivamente
e resolver problemas "impossíveis" com backtracking.

Linguagem: TypeScript

Lembrete: Formato Randori

Como vamos trabalhar hoje?

  • Apenas UM Driver: Ele não pensa a lógica, apenas digita o código (escuta a plateia).
  • A Plateia Pensa: Discutam as ideias em voz alta. Pensem coletivamente.
  • Rotação (3-5 min): Tocou o timer, o Driver sai. Um novo Driver assume imediatamente.
  • Errar faz parte: O código não precisa rodar de primeira.

O que é Recursão?

Uma função que chama a si mesma para resolver subproblemas menores.

Toda recursão precisa de: caso base + chamada recursiva

Anatomia de uma Função Recursiva


function fatorial(n: number): number {
    // Caso base: quando parar
    if (n <= 1) return 1;

    // Chamada recursiva: problema menor
    return n * fatorial(n - 1);
}
// fatorial(4) -> 4 * fatorial(3) -> 4 * 3 * fatorial(2)
// -> 4 * 3 * 2 * fatorial(1) -> 4 * 3 * 2 * 1 = 24

E o que é Backtracking?

Uma técnica de recursão onde tentamos uma escolha, avançamos, e se chegarmos a um beco sem saída, voltamos atrás e tentamos outra opção.

Pense em um labirinto: avance, se bateu na parede, volte e tente outro caminho.

Padrão de Backtracking


function backtrack(caminho: string[], opcoes: string[]) {
    if (condicaoDeSaida(caminho)) {
        resultados.push([...caminho]);
        return;
    }

    for (const opcao of opcoes) {
        caminho.push(opcao);       // Escolha
        backtrack(caminho, opcoes); // Explore
        caminho.pop();             // Desfaça (backtrack!)
    }
}

Round 1

Verificador de Palíndromo Recursivo

O Problema

Contexto (Spotify/Playlists): Você trabalha no Spotify e o time de produto quer criar uma feature divertida: identificar nomes de playlists que são palíndromos (lêem-se igual de trás pra frente). Sua tarefa é criar o algoritmo central.

Dada uma string, retorne true se ela for um palíndromo, ignorando espaços e diferenças de maiúscula/minúscula.


// Exemplos:
isPalindrome("arara")         // true
isPalindrome("Ame a Ema")     // true
isPalindrome("typescript")    // false
isPalindrome("Socorram me subi no onibus em Marrocos")  // true

Fase 1: Solução Iterativa (Two Pointers)

Plateia: Qual a estratégia mais direta? Dois ponteiros, um do início e outro do fim, caminhando ao centro.

Análise

  • Tempo: O(n) - percorremos metade da string.
  • Espaço: O(1) - apenas dois índices.

Agora, como transformar isso em recursão?

Fase 2: Versão Recursiva

Plateia: Qual o caso base? Qual a chamada recursiva?

  • Caso base: Se os ponteiros se cruzaram, é palíndromo.
  • Passo: Se chars são iguais, verifique o subproblema interno.
🔁 DRIVER 2: Refatore para uma solução recursiva pura (sem loops)!

Comparação

AbordagemTempoEspaço
Iterativa (two pointers)O(n)O(1)
RecursivaO(n)O(n) - call stack

Trade-off: Recursão é elegante mas usa mais memória (pilha de chamadas).

Round 2

Gerador de Parênteses Válidos

Problema clássico de entrevistas (Google, Meta, Amazon).

O Problema

Contexto (Compilador): Você está construindo um parser de expressões para um compilador. Precisa gerar todas as combinações válidas de parênteses para validar a gramática. Cada combinação representa uma estrutura de aninhamento diferente.

Dado um número n, gere todas as combinações válidas de n pares de parênteses.


// Exemplos:
generateParentheses(1) // ["()"]
generateParentheses(2) // ["(())", "()()"]
generateParentheses(3) // ["((()))", "(()())", "(())()",
                        //  "()(())", "()()()"]

Pensando no Backtracking

Professor: Quais são as regras para parênteses válidos?

  • Podemos abrir ( se ainda temos parênteses de abertura restantes.
  • Podemos fechar ) somente se o número de fechamentos for menor que o de aberturas.
  • Caso base: quando usamos todos os n pares.

Visualizando a Árvore de Decisão


                    ""
                   /
                  "("
                 /    \
              "(("    "()"
              /  \       \
           "(()" "(()   "()()"  <-- resultado!
            |       ...
          "(())"  <-- resultado!

Cada nó é uma escolha: abrir ou fechar. Backtracking poda os caminhos inválidos.

Hora de Codar!

Plateia: Guiem o Driver. Precisamos de:

  • Uma função recursiva com parâmetros: string atual, contagem de aberturas, contagem de fechamentos.
  • Duas decisões por chamada: adicionar ( ou ).
  • Condições de poda para evitar caminhos inválidos.
⚡ DRIVER 3: Implemente o gerador de parênteses usando backtracking!

Análise da Complexidade

  • Tempo: O(4^n / sqrt(n)) - número de Catalan.
  • Espaço: O(n) - profundidade da recursão.

Este é um problema onde NÃO existe solução polinomial simples. Backtracking é a abordagem correta!

Round 3

Permutações de String

O Problema

Contexto (Segurança/Criptografia): Você está em uma equipe de segurança e precisa gerar todas as permutações possíveis de uma chave parcial para um teste de força bruta controlado. Entender como gerar permutações é fundamental para compreender a complexidade de ataques criptográficos.

Dada uma string, gere todas as permutações possíveis dos seus caracteres (sem repetição).


// Exemplos:
permutations("ab")  // ["ab", "ba"]
permutations("abc") // ["abc", "acb", "bac", "bca",
                     //  "cab", "cba"]
// Para n caracteres: n! permutações
// 3! = 6, 4! = 24, 5! = 120...

A Estratégia: Backtracking com "Usados"

Professor: Para cada posição, escolhemos um caractere ainda não utilizado.

  • Escolha: Fixe um caractere na posição atual.
  • Explore: Preencha as posições restantes recursivamente.
  • Desfaça: Libere o caractere e tente o próximo.

Visualizando para "abc"


                       ""
                   /    |    \
                 "a"   "b"   "c"
                / \   / \    / \
             "ab" "ac" "ba" "bc" "ca" "cb"
              |    |    |    |    |    |
            "abc""acb""bac""bca""cab""cba"

Cada nível da árvore fixa um caractere. Backtracking garante que exploramos todas as combinações.

Implementação

Plateia: Pensem nos parâmetros da função recursiva:

  • A string original (ou array de chars)
  • Um array de boolean para marcar caracteres usados
  • A permutação sendo construída (string ou array)
  • Array de resultados
🛠️ DRIVER 4: Última rodada! Implemente as permutações com backtracking!

Análise Final

  • Tempo: O(n! * n) - n! permutações, cada uma com custo n para copiar.
  • Espaço: O(n) - profundidade da recursão + array de usados.

n! cresce explosivamente: com 10 caracteres já são 3.628.800 permutações!
