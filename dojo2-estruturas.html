Busca, Árvores e Zig!

Explorando estruturas não-lineares e uma nova linguagem moderna.

O que é Zig?

Uma linguagem de programação moderna de baixo nível, projetada para substituir o C.

"O sucessor espiritual do C"

Zig vs C: Principais Diferenças

  • Sem Fluxo Oculto: No Zig, não há pré-processador ou macros complexas. O que você lê é o que o processador executa.
  • Gerenciamento de Memória: Introduz o defer para garantir que a memória seja liberada sem erros.
  • Segurança: O compilador detecta estouros de array e erros de lógica em modo Debug.
  • Erros Explícitos: O tratamento de erro é obrigatório, usando o comando try.

Por que usar no Dojo?

O Zig nos obriga a pensar em cada detalhe (alocação, erros, limites) de forma muito mais clara que o C tradicional.

🚀 Vamos aprender uma estrutura de dados e uma linguagem nova ao mesmo tempo!

Round 1

Busca em Árvore Binária (BFS vs DFS)

O Problema

Contexto (File System): Você está criando um buscador de arquivos. As pastas são nós e os arquivos/subpastas são filhos. Você precisa encontrar se um arquivo específico existe na hierarquia.

Dada a raiz de uma Árvore Binária, verifique se um valor X existe nela.

Estratégia 1: DFS (Deep First)

Plateia: Vamos descer o máximo possível em um ramo antes de retroceder (Recursão!).

💻 DRIVER 1: Vá para o teclado! Implemente a busca usando Recursão (DFS).

Estratégia 2: BFS (Breadth First)

Plateia: E se quisermos buscar nível por nível? (Primeiro os vizinhos próximos).

Dica: Use uma FILA (Queue).

💻 DRIVER 2: Implemente a busca usando uma Fila (Iterativo - BFS).

Round 2

Caminho em Grafos (Rede Social)

O Problema

Contexto (LinkedIn): Você precisa saber se o Usuário A está conectado ao Usuário B (mesmo que por amigos de amigos).

Dado um Grafo (Lista de Adjacência), retorne se existe um caminho entre dois nós.

O Perigo dos Ciclos

Professor: Diferente de árvores, grafos podem ter ciclos (A -> B -> C -> A).

Como evitar que o Driver entre em loop infinito?

Plateia: Precisamos de um Set de "Visitados"!

⚡ DRIVER 3: Implemente a busca em Grafo garantindo que não visitamos o mesmo nó duas vezes.
